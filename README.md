# 幻梦星域 · Dream Star Domain

Minecraft **1.20.1 / Forge 47.4.0 / Java 17** 的独立铁魔法附属。
支持 **Minecraft 1.20.1 Forge 版 Iron's Spells 'n Spellbooks 3.16.0及以上**，不是替换本体的魔改包。
编译依赖固定为最低支持版 `1.20.1-3.16.0`，加载范围为 `[1.20.1-3.16.0,)`，无铁魔法版本上限。
更高版本仍需对应Minecraft 1.20.1和Forge；未来版本若改变接口，可能需要更新本附属。

## 0.2.0 内容

| 参数 | 默认值 |
| --- | --- |
| 法术 ID | `dreamstar:dream_star_domain` |
| 中文名 | 幻梦星域 |
| 学派 | 冰 |
| 品质 / 等级 | 传说 / 1级 |
| 法力 | 120 |
| 冷却 | 180秒 |
| 持续 | 600游戏刻，正常20 TPS时30秒 |
| 范围 | 施法时玩家位置为球心，半径40格的球形 |
| 施法方式 | 瞬发；结界中心固定，不随玩家移动 |

法力和冷却由铁魔法的正式施法系统处理，遵循本体的配置、装备和施法来源规则。
例如一次性卷轴遵循本体的卷轴规则；测试法力和冷却请先把法术铭刻到法术书，使用生存模式施法。
伤害、减速、困敌和友军判定尚未加入，这版先完成视觉结界。

星云使用相机射线与共享三维坐标生成；虚拟星空有近、中、远三层，并加入脚下的环状行星。
站在结界内低头看地面即可看到星球。星球位于结界中心下方的虚拟空间，不随玩家转头而旋转。
星球周围增加银河亮带、暗尘带与细小星云纹理。
玩家平移时，各层产生不同幅度的视差；旋转视角时，星空保持世界方向。
同一片星云跨方块衔接，没有每个方块重复一张图的接缝。
进入球形范围后，天空在约1.5秒内渐变为蓝紫银河天空，并绘制较多的分层云带、碎云和星光。
范围判定采用玩家位置；边界内2格为渐变带，越靠近内部天空越完整。
离开范围或结界结束，星空约1.5秒淡回原天空；重入会从当前混合程度平滑反转，切换世界/维度立即清理。
另有实际位于结界空气中的冰蓝星光粒子，以及持续生成在球形边缘方块表面的四芒星粒子。
边缘粒子检查方块实际形状与裸露面，兼顾地面、墙和天花板；空中没有方块的边界不生成表面粒子。
图标与地形着色器分开，图标不会用于方块表面。

结界只改客户端画面，不改方块、方块实体、碰撞或存档里的方块数据。
服务端用同步实体控制位置、半径和起始时间；600刻后删除，客户端有淡入淡出。
实体保留起始时间，因此区块重新加载不会重置30秒计时。

## 安装

客户端和服务端都安装本附属及依赖。先用启动器安装：

- Forge 47.4.0，Minecraft 1.20.1，Java 17。
- Iron's Spells 'n Spellbooks `1.20.1-3.16.0` 或更高的1.20.1 Forge版本。
- Iron's Lib `1.20.1-2.1.0`。
- Curios `5.14.1+1.20.1`。
- GeckoLib Forge `1.20.1-4.8.2`。
- Player Animator `1.0.2-rc1+1.20`。

以上库版本是工程的开发依赖组合；使用更高版本铁魔法时，请同时满足该版本本体声明的依赖要求。

将构建后的 `build/libs/dreamstar-1.20.1-0.2.0.jar` 放入实例的 `mods` 文件夹，并移出旧版本附属jar，避免重复加载。
不要把工程压缩包或开发用原始 jar 放进 `mods`。

进入允许作弊的测试世界：

```mcfunction
/dreamstar scroll
```

得到正式铁魔法卷轴后，可通过本体的铭刻流程加入法术书。
管理员也可用 `/dreamstar preview` 直接查看30秒视觉结界；此调试命令不扣法力、不触发冷却。

本版新释放结界固定半径40格；旧版 `serverconfig/dreamstar-server.toml` 中的 `radius=12` 不再生效，无需修改旧配置。
铁魔法自身的法术配置可以覆盖基础法力、冷却和品质；验证默认值请使用全新配置。

## 构建和开发

安装JDK 17，在此目录打开终端：

```powershell
.\gradlew.bat build
.\gradlew.bat shaderSmokeTest
.\gradlew.bat runClient
```

首次构建会联网下载 Gradle、Forge、Minecraft 与依赖。
`build` 包括时间边界测试并生成已重混淆的发布 jar。
`shaderSmokeTest` 在隐藏的OpenGL窗口中编译实际着色器，检验范围裁剪、天空/地形分离、相机移动视差以及天空透明度混合；需要可用显卡驱动。
图片报告在 `build/reports/shaders/`，它们是着色器测试画面，不是游戏内截图。

## 支持边界

- 覆盖普通实体方块和cutout地形（包括常规半砖、楼梯、树叶等实际网格轮廓）。
- 透明渲染层的水、玻璃，以及箱子等方块实体的独立渲染暂不替换。
- 地形先绘制、星域再覆盖、实体后绘制，所以玩家和生物不会被涂成星云。
- 普通/流畅画质是优先测试目标。外部光影、OptiFine/Oculus、特殊深度缓冲及其他渲染模组尚未承诺兼容。
- 银河天空先于地形绘制，保留地形遮挡，不会透过洞穴顶棚显示；原版天气和原版云仍按游戏的绘制顺序叠加。
- 为控制负载，同时绘制最近的最多8个结界，视距为半径外96格；单个结界无需扫描或重建区块。
- 当前没有添加实体护罩或碰撞墙；圆形边界由地形上的渐变遮罩表现。

## 代码位置

- `spell/DreamStarSpell.java`：冰系、品质、法力、冷却与法术注册接口。
- `domain/DomainEntity.java`：服务端时限、同步和存档。
- `client/DomainRenderer.java`：地形深度快照、范围遮罩、粒子、显卡状态恢复。
- `client/SkyTransition.java`：进入、退出和重入结界的天空渐变。
- `client/BoundaryParticles.java`：边界附近的实际方块表面检测。
- `assets/dreamstar/shaders/core/domain.fsh`：连续星云、星辰视差与环状行星。
- `assets/dreamstar/lang/`：中文、英文文本。
